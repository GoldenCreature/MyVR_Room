# 🎨 화가의 방 (Artist's Studio) - VR Room

## 프로젝트 소개
Unity XR Interaction Toolkit을 활용한 VR 화가의 방입니다.
붓을 집어 팔레트에서 색을 묻히고 캔버스에 그림을 그릴 수 있습니다.

## 개발 환경
- Unity 2022 LTS
- XR Interaction Toolkit 2.5.2
- Oculus Quest 2 (PC VR / Oculus Link)

## 핵심 기능
- 🎮 컨트롤러로 자유 이동 (Continuous Move)
- ✋ 붓, 팔레트 잡기 (XR Grab Interactable)
- 🎨 팔레트 색상 선택 → 붓 색상 변경
- 🖌️ 캔버스에 그림 그리기 (Trail Renderer)
- 🔥 난로에 캔버스 소각

## 사용 에셋
- 교수님 제공 패키지 (방, 가구, 이펙트)
- Free3D - Easel, Paint Brush
